시행일: 2026년 10월 26일

수집하는 정보

ShortsMaker는 YouTube 업로드 권한(youtube.upload)만 요청합니다. 이 권한은 운영자 본인의 채널에 운영자가 만든 영상을 업로드하는 데에만 사용됩니다. 이름, 이메일, 시청 기록, 구독 정보 등 다른 개인정보는 읽거나 수집하지 않습니다.

정보의 저장과 공유

로그인 토큰은 운영자 본인의 컴퓨터와 운영자 본인의 비공개 저장소 비밀 설정에만 저장되며, 제3자에게 판매하거나 공유하지 않습니다.

권한 철회

Google 계정 설정의 '서드 파티 앱 및 서비스'에서 언제든지 ShortsMaker의 접근 권한을 삭제할 수 있습니다.

Google API 사용

ShortsMaker의 Google API 정보 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.
